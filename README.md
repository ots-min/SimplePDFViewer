# SimplePDFViewer
シンプルなPDFビューワです

SimplePDFViewer使い方

○機能/ショートカット一覧

単語検索         Ctrl+F(Enter=次へ、Shift+Enter=前へ)。F3/Escでも開く/閉じる
拡大/縮小        Ctrl+ホイール, Ctrl++/Ctrl+-, ツールバー
100%に設定       Ctrl+1(ツールバーの「100%」)
幅に合わせる     Ctrl+0
ページ移動       PageUp/PageDown、Home/End、←/→、ツールバー、ページ番号入力
表示方法         Ctrl+2=1ページ、Ctrl+3=見開き2ページ
                 Ctrl+4=1ページ目の単独表示切替
綴じ方向(見開き) Ctrl+5=左綴じ/右綴じ切替
                 (右綴じでは右ページが先、←キーが「次へ」になる)
印刷             Ctrl+P(ツールバーの「印刷」)で印刷ダイアログを表示
画像として保存   Ctrl+S(PDFと同じフォルダへ「PDF名_p001.png」のように保存)
フルスクリーン   Ctrl+L(Escで解除)。ページ全体が画面に収まる倍率へ自動調整
テキスト選択     左ドラッグで範囲選択
                 ダブルクリックで単語、トリプルクリックで行、 Ctrl+Aで全選択
テキストのコピー テキストを選択した状態でCtrl+C
スクロール       ホイール、右と下のスクロールバー
                 テキスト以外の場所を左ドラッグ→表示領域をスクロール

○補足

・レイアウトは、1ページ/見開き2ページで切り替えが可能。縦長のページのときは、見開き表示が便利です。

・見開きのときには、左綴じ/右綴じが選べます。コミックスなど右から左に読む場合は、右綴じにしてください。「1ページ目単独」にチェックを入れると、1ページ目の表紙だけは見開きにせず、単独で表示します。

・ウィンドウは、通常モードとフルスクリーンモードの切り替えが可能です。フルスクリーンに切り替えると、表示倍率を自動調整して画面一杯に表示させます。

・上記の設定は保存され、プログラムの次回起動時に復元されます。保存した設定はPC共通で、PDFファイルごとに設定できるわけではありません。設定ファイルは C:\Users\<ユーザー名>\AppData\Roaming\PDFViewer にあります。

・起動時には、画面の80%サイズでウィンドウが表示されます。それに合わせて表示倍率を自動設定します。

・ページサイズが表示エリアより広い場合、文字以外の場所を左ドラッグすることで、表示領域をスクロールさせられます。文字の上を左ドラッグすると、テキストを選択できるので、Ctrl+Cでクリップボードにコピーしてください。

・右上の「印刷」ボタンを押すと、汎用の印刷ダイアログが表示されるので、プリンタを指定して印刷してください。右側にはプレビュー画面がありますが、残念ながら対応していないので、ここには何も表示されません。
